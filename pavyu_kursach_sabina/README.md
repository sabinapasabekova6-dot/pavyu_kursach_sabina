## 5. Формат входного/выходного файла

Программа использует текстовые файлы с расширением .txt. Файл состоит из двух логических частей:

1. **Первая строка** — служебная, всегда начинается с ключевого слова PARAMS, за которым следуют параметры преобразования.
2. **Последующие строки** — описывают точки маршрута, по одной точке на строку.

Различают два типа файлов в зависимости от того, применялось ли преобразование координат перед сохранением.

### 5.1. Файл no_full.txt (маршрут без применённого преобразования)

Пример содержимого:

    PARAMS 0 0 0
    5 67 88
    4 67 99
    2 -9 0
    1 -32.23 -0.043

**Построчный разбор:**

**Строка 1:** PARAMS 0 0 0
- PARAMS — служебное ключевое слово, обозначающее начало строки параметров.
- 0 (первое) — угол поворота в градусах. Значение 0 означает, что поворот не выполнялся.
- 0 (второе) — координата X начала исходной системы координат в целевой. Значение 0 означает отсутствие сдвига по X.
- 0 (третье) — координата Y начала исходной системы координат в целевой. Значение 0 означает отсутствие сдвига по Y.
- Смысл строки: преобразование не применялось, либо применялось с нулевыми параметрами (тождественное преобразование).

**Строка 2:** 5 67 88
- 5 — ID точки (уникальный номер).
- 67 — исходная координата X.
- 88 — исходная координата Y.
- Целевые координаты TX и TY отсутствуют, поскольку преобразование не применялось.

**Строка 3:** 4 67 99
- 4 — ID точки.
- 67 — исходная координата X.
- 99 — исходная координата Y.

**Строка 4:** 2 -9 0
- 2 — ID точки.
- -9 — исходная координата X (отрицательная).
- 0 — исходная координата Y.

**Строка 5:** 1 -32.23 -0.043
- 1 — ID точки.
- -32.23 — исходная координата X (дробное отрицательное число).
- -0.043 — исходная координата Y (дробное отрицательное число).

**Итог:** файл содержит 4 точки без применённого преобразования. При загрузке такого файла программа восстановит точки с исходными координатами, а флаг isTransformed для них будет равен false.

### 5.2. Файл full.txt (маршрут с применённым преобразованием)

Пример содержимого:

    PARAMS 90 5 5
    1 0 0 5 5
    2 10 0 5 15
    3 10 10 -5 15

**Построчный разбор:**

**Строка 1:** PARAMS 90 5 5
- PARAMS — служебное ключевое слово.
- 90 — угол поворота в градусах (против часовой стрелки).
- 5 — координата X начала исходной системы координат в целевой (сдвиг по X).
- 5 — координата Y начала исходной системы координат в целевой (сдвиг по Y).
- Смысл строки: к маршруту было применено аффинное преобразование с указанными параметрами.

**Строка 2:** 1 0 0 5 5
- 1 — ID точки.
- 0 — исходная координата X (до преобразования).
- 0 — исходная координата Y (до преобразования).
- 5 — целевая координата TX (после преобразования).
- 5 — целевая координата TY (после преобразования).
- Смысл строки: точка №1, находившаяся в (0, 0), после поворота на 90° и сдвига на (5, 5) оказалась в (5, 5).

**Строка 3:** 2 10 0 5 15
- 2 — ID точки.
- 10 — исходная X.
- 0 — исходная Y.
- 5 — целевая TX.
- 15 — целевая TY.
- Точка №2 была в (10, 0), стала в (5, 15).

**Строка 4:** 3 10 10 -5 15
- 3 — ID точки.
- 10 — исходная X.
- 10 — исходная Y.
- -5 — целевая TX (отрицательная после поворота).
- 15 — целевая TY.
- Точка №3 была в (10, 10), стала в (-5, 15).

**Итог:** файл содержит 3 точки с применённым преобразованием. При загрузке такого файла программа восстановит как исходные, так и целевые координаты, а флаг isTransformed для каждой точки будет равен true.

### 5.3. Общие правила формата

- Все числа в одной строке разделены одиночным пробелом.
- Дробные числа записываются через точку (например, -32.23), а не через запятую. Это обеспечивается использованием locale("C") при работе с потоками.
- Порядок точек в файле соответствует порядку их обхода в двусвязном списке (от head к tail).
- Первая строка файла обязательно должна начинаться с PARAMS — иначе программа откажет в загрузке.

## 6. Идентификатор (ID) точки и его назначение

**ID** — это уникальный целочисленный номер, присваиваемый каждой точке маршрута при её создании.

**Назначение ID:**

1. **Однозначная идентификация точки.** Даже если две точки имеют одинаковые координаты, они различаются по ID.
2. **Поиск точки для редактирования и удаления.** Команды «Изменить точку» и «Удалить точку» работают именно по ID.
3. **Указание позиции вставки.** Команда «Добавить после точки» принимает ID существующей точки как ориентир.
4. **Сохранение порядка в файле.** При загрузке из файла ID восстанавливаются, что позволяет сохранить исходную нумерацию.
5. **Предотвращение конфликтов.** Программа отслеживает максимальный использованный ID и при добавлении новой точки выдаёт следующий номер, чтобы не допустить дублирования.

**Принцип работы:**

- При создании первой точки ей присваивается ID = 1, глобальный счётчик nextId увеличивается до 2.
- При создании второй точки присваивается ID = 2, счётчик становится равным 3. И так далее.
- ID не перенумеровываются после удаления точек. Если были точки с ID 1, 2, 3 и удалена точка 2, то оставшиеся точки сохраняют ID 1 и 3.
- При загрузке файла, содержащего точки с ID 1, 2, 3, 5, программа устанавливает nextId = 6, чтобы следующая добавленная вручную точка не получила уже занятый номер.

**Пример:**

    Добавили точку A   ID = 1
    Добавили точку B   ID = 2
    Добавили точку C   ID = 3
    Удалили точку B (ID = 2)
    Добавили точку D   ID = 4  (а не 2 — чтобы не было конфликта!)

## 7. Пошаговая работа с каждым пунктом меню

Главное меню программы содержит следующие пункты:

    1. Добавить точку маршрута
    2. Редактировать / удалить точку
    3. Просмотреть маршрут
    4. Задать параметры и применить преобразование
    5. Показать математический аппарат
    6. Вычислить длину маршрута
    7. Сохранить в файл
    8. Загрузить из файла
    9. Очистить маршрут
    0. Выход

### Пункт 1. Добавить точку маршрута

**Назначение:** создание новой точки и её вставка в двусвязный список.

**Порядок действий:**

1. В главном меню выберите пункт 1, нажмите Enter.
2. Откроется подменю:
   - Добавить в НАЧАЛО маршрута
   - Добавить в КОНЕЦ маршрута
   - Добавить МЕЖДУ точками (после указанной)
   - Вернуться в главное меню
3. Выберите нужный вариант стрелками и подтвердите Enter.
4. Программа запросит координаты:
   - «Введите X: » — введите число (например, 5.5).
   - «Введите Y: » — введите число (например, -3.2).
5. Для варианта «Добавить МЕЖДУ точками» дополнительно запрашивается ID существующей точки, после которой будет выполнена вставка. Если точка с таким ID не найдена, программа выдаст сообщение об ошибке и вернётся в подменю.

**Результат:** новая точка добавлена в маршрут, ей присвоен следующий уникальный ID, выведено сообщение с указанием нового ID.

**Правила ввода чисел:**
- Допускаются целые и дробные числа, положительные и отрицательные.
- Разделитель дробной части — точка. Если Вы введёте запятую (например, 5,5), программа автоматически заменит её на точку.
- При некорректном вводе (буквы, пустая строка, недопустимый формат) программа выводит сообщение об ошибке и запрашивает повторный ввод.
- Для возврата в подменю без добавления точки введите #.

### Пункт 2. Редактировать / удалить точку

**Назначение:** изменение координат существующей точки или её удаление из маршрута.

**Порядок действий:**

1. В главном меню выберите пункт 2, нажмите Enter.
2. Откроется подменю:
   - Изменить точку по ID
   - Удалить точку по ID
   - Вернуться в главное меню
3. Выберите нужный вариант.

**При редактировании:**
- Программа запросит ID точки, которую нужно изменить.
- Затем запросит новые координаты X и Y.
- После подтверждения точка обновляется, выводится сообщение об успехе.
- Если точка ранее была преобразована, при изменении исходных координат целевые координаты сбрасываются (флаг isTransformed становится false), поскольку преобразование больше не актуально.

**При удалении:**
- Программа запросит ID удаляемой точки.
- Точка извлекается из двусвязного списка с корректной перенастройкой указателей prev и next у соседних узлов, а также обновлением глобальных указателей head и tail при удалении крайних элементов.
- Память, занимаемая удалённым узлом, освобождается оператором delete (предотвращение утечки памяти).
- Выводится сообщение об успешном удалении.

**Обработка ошибок:** если точка с указанным ID не найдена, программа выводит сообщение об ошибке и возвращает в подменю.

### Пункт 3. Просмотреть маршрут

**Назначение:** отображение всех точек маршрута в виде форматированной таблицы.

**Порядок действий:**

1. В главном меню выберите пункт 3, нажмите Enter.
2. Откроется подменю:
   - Просмотр в ПРЯМОМ порядке (от первой точки к последней)
   - Просмотр в ОБРАТНОМ порядке (от последней точки к первой)
   - Вернуться в главное меню
3. Выберите порядок просмотра.

**Результат:** на экран выводится таблица с колонками:

- **ID** — номер точки.
- **X (исх)** — исходная координата X.
- **Y (исх)** — исходная координата Y.
- **TX (цел)** — целевая координата X (после преобразования), либо --- если преобразование не применялось.
- **TY (цел)** — целевая координата Y, либо ---.

**Пример вывода:**

    ID    | X (исх)        | Y (исх)        | TX (цел)       | TY (цел)
    ---------------------------------------------------------------------------
    1     | 0              | 0              | 5              | 5
    2     | 10             | 0              | 5              | 15
    3     | 10             | 10             | -5             | 15

**Особенность:** обратный порядок просмотра возможен благодаря тому, что структура данных реализована как двусвязный список — каждый узел хранит указатель prev, что позволяет начать обход с tail и двигаться к head за линейное время O(N) без дополнительной памяти.

### Пункт 4. Задать параметры и применить преобразование

**Назначение:** ввод параметров взаимного положения двух систем координат и выполнение аффинного преобразования ко всем точкам маршрута.

**Порядок действий:**

1. В главном меню выберите пункт 4, нажмите Enter.
2. Программа проверит, не пуст ли маршрут. Если пуст — выведет сообщение и вернётся в меню.
3. Запрос будут введены три параметра:
   - «Введите угол поворота (в градусах, против часовой стрелки): » — например, 90.
   - «Введите X начала исходной СК в целевой СК: » — например, 5.
   - «Введите Y начала исходной СК в целевой СК: » — например, 5.
4. После ввода программа:
   - построит матрицу прямого преобразования 3?3;
   - построит матрицу обратного преобразования;
   - применит прямое преобразование ко всем точкам маршрута, вычислив для каждой точки целевые координаты TX и TY;
   - установит флаг isTransformed = true для всех точек.
5. Выводится сообщение: «Преобразование успешно применено ко всем точкам маршрута!».

**Математическая суть преобразования:**

Для каждой точки с исходными координатами (X, Y) вычисляются целевые координаты по формулам:

    TX = X·cos(α) - Y·sin(α) + originX
    TY = X·sin(α) + Y·cos(α) + originY

где α — введённый угол в радианах, originX и originY — введённый сдвиг.

### Пункт 5. Показать математический аппарат

**Назначение:** демонстрация матрицы преобразования, явных формул и проверка корректности вычислений через обратное преобразование.

**Порядок действий:**

1. В главном меню выберите пункт 5, нажмите Enter.
2. На экран выводятся три раздела.

**Раздел 1. Матрица прямого преобразования (3×3):**

    | 0         -1        5         |
    | 1          0        10        |
    | 0          0        1         |

Матрица записана в однородных координатах: левый верхний блок 2×2 отвечает за поворот, правый столбец — за перенос, нижняя строка [0 0 1] обеспечивает корректность матричного умножения.

**Раздел 2. Формулы прямого перехода с числовыми коэффициентами:**

    X_new = 0 * X + (-1) * Y + 5
    Y_new = 1 * X + 0 * Y + 10

**Раздел 3. Проверка обратного преобразования (восстановление исходных координат):**

Выводится таблица:

    ID | Исходные (X,Y) | Целевые (TX,TY) | Восстановленные | Погрешность
    1  | (0, 0)         | (5, 5)          | (0, 0)          | 0, 0
    2  | (10, 0)        | (5, 15)         | (10, 0)         | 0, 0

**Как работает проверка:** для каждой точки к её целевым координатам (TX, TY) применяется матрица обратного преобразования, в результате чего получаются «восстановленные» координаты. Они сравниваются с исходными (X, Y), и вычисляется модуль разности — погрешность. Если преобразования реализованы корректно, погрешность стремится к нулю (с учётом машинной точности чисел с плавающей запятой).

**Важно:** проверка не изменяет данные в структуре — исходные координаты остаются неизменными, восстановленные значения вычисляются во временных переменных.

### Пункт 6. Вычислить длину маршрута

**Назначение:** расчёт суммарной длины ломаной линии, образованной последовательным соединением всех точек маршрута.

3. Выполняется обход списка от head до предпоследней точки. Для каждой пары соседних точек вычисляется расстояние по теореме Пифагора:
4. Все расстояния суммируются.
5. Выводится результат вида: «Длина маршрута: 45.67 единиц».

**Математическое свойство:** длина маршрута является инвариантом относительно аффинного преобразования (поворота и переноса). Это означает, что длина ломаной до преобразования и после него совпадает (с точностью до машинной погрешности). Данное свойство используется как дополнительная проверка корректности программы.

### Пункт 7. Сохранить в файл

**Назначение:** запись текущего маршрута и параметров преобразования в текстовый файл.

**Порядок действий:**

1. В главном меню выберите пункт 7, нажмите Enter.
2. Программа проверит, не пуст ли маршрут. Если пуст — выведет сообщение и вернётся в меню.
3. Появится запрос: «Введите имя файла для сохранения (или нажмите # для возврата в меню): ».
4. Введите имя файла, например my_route. Программа автоматически добавит расширение .txt, если Вы его не указали.
5. Если имя файла некорректно, программа выведет конкретное диагностическое сообщение и повторит запрос. Возможные ошибки и их формулировки:
   - Пустое имя -> «Ошибка: имя файла не может быть пустым!»
   - Наличие пробелов -> «Ошибка: имя файла не должно содержать пробелы!»
   - Запрещённые символы (< > : " / \ | ? * + = ; ) -> «Ошибка: имя файла содержит запрещённый символ 'X'!»
   - Неверное расширение -> «Ошибка: файл должен иметь расширение .txt (введено расширение: .doc)!»
   - Имя вида .txt (без базового имени) -> «Ошибка: базовое имя файла не может быть пустым!»
   - Для отмены операции введите # — программа вернётся в главное меню.
6. После корректного ввода программа откроет файл для записи и запишет:
   - первую строку PARAMS угол originX originY;
   - по одной строке на каждую точку в формате ID X Y (или ID X Y TX TY, если преобразование применялось).
7. Выводится сообщение: «Данные успешно сохранены в файл "my_route.txt"!».

### Пункт 8. Загрузить из файла

**Назначение:** восстановление маршрута и параметров преобразования из текстового файла.

**Порядок действий:**

1. В главном меню выберите пункт 8, нажмите Enter.
2. Появится запрос: «Введите имя файла для загрузки (или введите # для возврата в меню): ».
3. Введите имя файла, например my_route.txt.
4. Программа выполняет многоступенчатую проверку:
   - **Существование файла.** Если файл не найден или не может быть открыт — выводится сообщение и запрашивается повторный ввод.
   - **Непустота файла.** Если файл пуст или содержит только пустые строки — выводится сообщение «Файл пуст!» и запрашивается повторный ввод.
   - **Формат данных.** Первая непустая строка должна начинаться с ключевого слова PARAMS. Если это не так — выводится сообщение о некорректном формате и запрашивается повторный ввод.
   - Для отмены операции введите #.
5. После прохождения всех проверок программа:
   - очищает текущий маршрут (освобождает память всех узлов);
   - сбрасывает счётчик ID;
   - открывает файл заново и читает его построчно;
   - восстанавливает параметры преобразования из строки PARAMS;
   - восстанавливает все точки маршрута, включая их целевые координаты (если они присутствуют в файле);
   - синхронизирует счётчик nextId с максимальным ID, загруженным из файла.
6. Выводится сообщение: «Маршрут успешно загружен из файла "my_route.txt"!», а при наличии строки PARAMS — дополнительно «Параметры преобразования также восстановлены.».

**Важно:** перед загрузкой текущий маршрут полностью удаляется. Если Вы хотите сохранить текущие данные, выполните их сохранение (пункт 7) до загрузки.

P.s. Выходной файл из программы может быть входным файлом для программы

### Пункт 9. Очистить маршрут

**Назначение:** полное удаление всех точек из структуры с освобождением динамической памяти.

**Порядок действий:**

1. В главном меню выберите пункт 9, нажмите Enter.
2. Программа выполняет безопасное освобождение памяти: обходит список от head до tail, для каждого узла сохраняет указатель на следующий, удаляет текущий узел оператором delete, затем переходит к следующему.
3. После очистки глобальные указатели head и tail устанавливаются в nullptr, счётчик nextId сбрасывается в 1.
4. Выводится сообщение о том, что маршрут очищен.

**Особенность реализации:** временный указатель temp используется для того, чтобы не потерять ссылку на следующий узел после удаления текущего. Это стандартный и безопасный способ освобождения памяти связного списка.

## 9. Структура проекта (более подробно)

Проект разбит на шесть файлов, каждый из которых несёт определённую функциональную нагрузку. Такое разделение обеспечивает модульность, читаемость и удобство сопровождения кода.

### 9.1. Total_Header.h — заголовочный файл

**Содержит:**
- определения макросов (M_PI);
- подключение стандартных библиотек (iostream, string, windows.h, fstream, sstream, conio.h, cmath, iomanip, locale);
- определение структуры PointNode (узел двусвязного списка: ID, исходные координаты X и Y, целевые координаты TX и TY, флаг isTransformed, указатели prev и next);
- определение структуры TransformMatrix (матрица 3?3 в виде двумерного массива double m[3][3]);
- объявления глобальных переменных с ключевым словом extern (указатели head, tail, счётчик nextId, матрицы matrix и invMat, параметры angleDeg, originX, originY);
- прототипы всех функций программы.

**Назначение:** единая точка описания структур данных и интерфейсов для всех модулей проекта.

**Содержит:**

- addPointLast(x, y) — добавление точки в конец списка;

- editPointById(id, x, y) — изменение координат существующей точки;
- clearList() — полное освобождение памяти всех узлов списка.

**Назначение:** реализация всех операций над структурой данных «двусвязный список».
